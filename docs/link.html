二、📖 蒙学诗文

  • 🔗 唐诗三百首（注音版）：poem300 —— 每首诗逐字标注拼音，适合小朋友，也适合突然忘了某个字该怎么念的大人。
  • 🔗 九十年代小学语文课本：xxyuwen_book —— 1 至 12 册课本图片展，一代人的共同记忆，翻开就是小时候。
  • 🔗 古诗文吟诵教程：yinsong-tutorial-docs —— 传统吟诵的方法与资料汇编，docsify 编写。

三、🧰 在线小工具

  • 🔗 实用在线工具箱：remark —— B 站视频字幕转文字稿、文件在线合并，打开浏览器就能用。
  • 🔗 飞书文档下载工具：feishu_apj_download —— 把飞书文档下载成 Markdown + 图片的命令行小工具，附完整使用文档。
  • 🔗 B 站字幕转文字：bilibili-video-text-conversion-project —— 把 ass 字幕文件转换成纯文本稿。
  • 🔗 Pages 部署示例：hws-zjshl —— Markdown 文档如何用 GitHub Pages 发布的最小示例，新手可照抄作业。
